# Stock Portfolio Tracker

A simple Python-based Stock Portfolio Tracker that calculates the total investment based on stock quantity and price per share.

## Features

- Takes user's name as input
- Takes stock name
- Takes quantity of shares
- Takes price per share
- Calculates total investment
- Displays a clear portfolio summary

## Technologies Used

- Python

## How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Run `stock.tracker.py`.
4. Enter your name, stock name, quantity, and price per share.

## Example

Quantity: 10  
Price per share: 3500  
Total Investment: 35000
